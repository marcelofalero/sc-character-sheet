# StarCraft Ghost RPG // Living Document & Interactive Character Sheet

A responsive, sci-fi tactical interactive character sheet and living rules compendium built for the StarCraft Ghost RPG ruleset.

---

## 🌟 Features

- **🪪 Live Interactive Character Sheet**: Point-buy attribute calculator (9 starting points), real-time derived statistics (Defense, Discipline, Toughness $15\ (8)$, Resolve $10$, Speed $6"$, Wounds, Fatigue), 17 custom skills with high Intelligence bonuses, and damage trackers.
- **⚡ Active Power Stances & 3-State Buffs**: One-click segmented controls (`Off` | `Success (+1)` | `Raise (+2)`) for *Hostile Environment Suit*, *Muscular Enhancement*, *Digital Uplink II*, *Rush*, *Thought Blocking*, and *Stimpacks*.
- **🎲 Built-in Tactical Dice Engine**: Exploding dice (Aces), Savage Wild Die ($d6$), Target Number 4 and Raise calculations, plus clickable in-text dice chips (`2d8+2`, `Str+d4`, `d8`, etc.).
- **📖 Complete Rules Compendium**: Full text across 10 chapters, including 7 Homeworlds, 17 Skills, 181 Edges, 63 Hindrances, 61 Psionic Powers across 6 disciplines, Armory, and Cybernetics.
- **⚡ High-Performance Rendering**: Powered by modern CSS `content-visibility: auto` for smooth 60+ FPS scrolling across 3,700+ compendium elements.
- **💾 Auto-Save & Export**: Persistent `localStorage` state, JSON export/import for character backups, and print/PDF-ready stylesheets.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local server:

```bash
# Start local server
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080`.
